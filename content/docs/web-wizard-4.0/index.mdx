## About the Event

**Web Wizard** is a flagship hands-on web development boot camp and hackathon
organized by **Google Developer Groups (GDG) on Campus** at **Ramdeobaba
University (RBU), Nagpur**.

This is **Edition 4.0** — our most comprehensive installment yet. We take
students from zero to deploy-ready, covering everything from crafting their
first HTML page to building full-stack applications backed by real databases.

## What You'll Learn

The boot camp is structured across multiple tracks:

| Track | Topics |
| --- | --- |
| **Frontend** | HTML, CSS, Tailwind CSS, JavaScript — building responsive, interactive UIs |
| **Backend** | Node.js, Express, REST APIs, databases — powering your site with real data |
| **Git & GitHub** | Version control, collaboration, open-source workflows |
| **Deployment** | Hosting strategies, making your site live on the internet |
| **AI for Web** | Leveraging AI tools to accelerate development, debugging, and design |

## Hands-on Format

Every session is built around live coding. You won't just watch slides — you'll
write real code, break things, fix them, and walk away with working projects.

## Who Can Join

Open to all RBU students. No prior web development experience needed — we start
from the absolute basics and build up.
